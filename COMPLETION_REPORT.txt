================================================================================
                              QUICK START GUIDE
================================================================================

INSTALLATION:
  1. Navigate to project directory
  2. Run: pip install -r requirements.txt

RUNNING THE GAME:
  
  Pygame GUI Version:
    python3 main.py
  
  CLI Text-Based Version:
    python3 cli_game.py

RUNNING TESTS:
  python3 test_game.py

GAME OBJECTIVE:
  Maximize portfolio value from $10,000 to as high as possible in 365 days

GAME RULES:
  • Starting balance: $10,000
  • Operations per day: Maximum 2 trades
  • Game duration: 365 days (1 year)
  • Investment types: Stocks, Crypto, Bonds, ETFs, Forex
